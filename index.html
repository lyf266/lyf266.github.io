    核心痛点与问题
    Linux 下 USB 摄像头在默认 MJPG 采集时遇坏包触发 FFmpeg 软件解码崩溃死循环；叠加 WebM 透明动效时 GPU 硬解码（NVDEC）会剥离 alpha 通道导致抠像全黑；OBS 重载场景时坐标漂移到画布中心。
    方法策略与工程实现
    锁定未压缩 YUYV 4:2:2 原始像素直采（OBS format 1448695129）完全绕过 FFmpeg 软解；配置 udev 规则禁用 USB autosuspend；双向同步计算 pos 绝对像素与 pos_rel 相对归一化坐标；WebM 强制 libvpx 软解保留 32 位全透明通道；进程内 Lua 定时器驱动动态时间。
    架构设计与关键约束
    实现广播级画质与零外部常驻后台进程，彻底免疫 USB 总线丢包与驱动崩溃。
    局限权衡与后续演进
    硬件参数针对特定型号深度加固，跨机使用需根据摄像头 VID/PID 重新绑定 udev 规则。
